Lesson Editor

Create a lesson by entering its YouTube link and transcript paragraphs.

Transcript format:
Put one paragraph on each line. Use [S] for a short pause and [L] for a long pause. Example: Hello there. [S] Today we will practice English. [L]

Enter times in seconds. Each paragraph must have a start and end time.

The first line of timestamps belongs to the first paragraph, the second line to the second paragraph, and so on. Example: 0|8 means start at 0 seconds and pause at 8 seconds.
